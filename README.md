# Amaury Automation

Página inicial para reunir projetos em desenvolvimento, criada com React e Vite.
O layout original tem navegação lateral, uma área de projetos preparada para
conteúdo futuro e alternância de tema, com modo escuro como padrão.

## Executar localmente

```powershell
npm install
npm run dev
```

## Gerar build de produção

```powershell
npm run build
npm run preview
```
