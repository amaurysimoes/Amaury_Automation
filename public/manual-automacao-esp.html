Automação ESP: do download ao ESP no Firebase

Este manual leva você, passo a passo, de um computador sem nada instalado até um ESP32 ligado, aparecendo no portal e com os pinos sob controle.

Visão geral

O projeto Python (automacao_esp) é um programa de desktop: ele monta o firmware, grava o ESP32 pela USB e define o Wi-Fi e os pinos. Depois de gravado, o ESP se conecta sozinho ao Firebase, e o portal (Aplicações IOT → AUTOMAÇÃO ESP) lista o ESP e aciona os pinos pela internet.

1. Instalar o Python

  1. Baixe o Python 3.10 ou mais novo em python.org/downloads.
  2. No instalador, marque Add python.exe to PATH e clique em Install Now.
  3. Confirme no PowerShell:
python --version

2. Instalar o VS Code

Baixe em code.visualstudio.com e instale. Opcional, mas recomendado: na aba Extensões, instale Python (Microsoft).

3. Baixar e abrir o projeto

  1. No portal, abra o painel AUTOMAÇÃO ESP e clique em Baixar projeto Python (.zip).
  2. Extraia o .zip. Você terá a pasta automacao_esp.
  3. No VS Code: Arquivo → Abrir Pasta… e escolha automacao_esp.
  4. Abra o terminal do VS Code: Terminal → Novo Terminal.

4. Criar o ambiente e instalar as bibliotecas

No terminal do VS Code (dentro de automacao_esp):

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

Se o PowerShell bloquear o activate, rode antes Set-ExecutionPolicy -Scope Process Bypass e tente de novo.

5. Criar o arquivo .env

O .env guarda o que é só seu (Wi-Fi e chave). Ele fica ao lado do main.py e nunca deve ser enviado ao GitHub nem compartilhado. 

Copy-Item .env.example .env

Abra o .env no VS Code e preencha:

ChaveO que colocar
ESP_NOMENome do ESP (letras, números, - e _). Aparece no Firebase como esps/<nome>.
ESP_MODELOESP32
WIFI_SSIDNome da sua rede Wi-Fi (2,4 GHz).
WIFI_SENHASenha do Wi-Fi.
FIREBASE_HOSTJá vem preenchido, sem https://.
FIREBASE_AUTHOpcional. Chave do banco; deixe em branco se as regras do seu banco permitem o ESP gravar.

Os valores do .env preenchem o formulário do programa; o que estiver em branco continua editável nele.

6. Executar o programa

Com a .venv ativa, no terminal do VS Code:

python main.py

O formulário Automação FireBase abre. Dica: no VS Code, abra o main.py e use o botão ▶ no canto superior direito.

7. Opcional: criar o executável (.exe)

Para usar sem abrir o VS Code, gere um executável de Windows:

pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name AutomacaoESP --icon assets\icone_ia.ico --add-data "assets;assets" --add-data "firmware\Automacao;firmware\Automacao" main.py
  • O arquivo fica em dist\AutomacaoESP.exe.
  • Coloque o .env na mesma pasta do .exe.
  • O programa grava o ESP usando o PlatformIO: instale-o também fora da .venv com pip install platformio.
  • O Windows pode avisar sobre executável sem assinatura digital (Mais informações → Executar assim mesmo).

8. Gravar o ESP32

  1. Ligue o ESP32 no computador por um cabo USB de dados. Se a porta não aparecer, instale o driver CP210x ou CH340 da sua placa.
  2. No programa, confira nome, Wi-Fi e a lista de pinos (GPIO, nome, saída ou entrada).
  3. Escolha a porta serial e clique para gravar. A primeira vez demora, pois o PlatformIO baixa as ferramentas.
  4. Ao terminar, o ESP reinicia, conecta ao Wi-Fi e se registra sozinho no Firebase.

9. Controlar pelo portal

  1. Abra o portal e, na seção Aplicações IOT, clique em AUTOMAÇÃO ESP.
  2. Em até cerca de 30 segundos o ESP aparece com o ponto verde (online).
  3. Clique nele para ver os pinos: Ligar/Desligar e Pulso nas saídas; as entradas mostram ON/OFF.

O portal lista os ESPs do banco padrão (FIREBASE_HOST do .env.example). Se você usar outro banco, o ESP aparecerá apenas nele.

Problemas comuns

  • "PlatformIO não encontrado": rode pip install platformio e abra o programa de novo.
  • Porta serial não aparece: troque o cabo (precisa ser de dados) e instale o driver da placa.
  • ESP não fica online: confira SSID e senha (rede 2,4 GHz) e se o computador e o ESP têm internet.
  • Erro ao gravar: segure o botão BOOT do ESP32 no início da gravação e tente de novo.
